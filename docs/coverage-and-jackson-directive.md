# 5-Day Coverage Plan + Jackson's Daily Directive
_For when Trish is out (Montana). Keep support + sales running safely, no owner needed._

---

## PART A — Safe autopilot (runs without a human)

**Live 24/7, no action needed:**
- **WrapGuru (site chat)** — answers questions, quotes wraps from the fixed price
  catalog, gives real cart links, runs the real file check, and offers ShopFlow
  fixes with a Stripe checkout the customer clicks themselves.
- **Escalations auto-route** — bulk / design / quality / support requests from
  chat land in the team inbox (jackson@, design@) automatically.
- **Retargeting** — safe, non-emailing jobs run on schedule.

**Safety guardrails already in place (why this is safe to leave):**
- WrapGuru only quotes the fixed catalog — it can't improvise prices.
- **No customer is charged unless they click a Stripe checkout themselves.**
- **Nothing goes to print without proof approval** (ApprovePro gate).
- Retargeting **customer emails stay OFF** unless you turn them on before you go.

**The safe sales engine while you're away = three levers:**
1. Content (Jackson, daily) driving traffic to WrapGuru.
2. WrapGuru converting that traffic (quotes emailed + retargeting enrollment).
3. Jackson following up unconverted leads + finishing design jobs.

---

## PART B — Jackson's Daily Directive (repeat every workday)

### 1. Morning sweep — Support + Sales (30–45 min)
- [ ] Check the team inbox for **WrapGuru escalations** — reply within a few hours.
- [ ] Check **new $199 File Output orders**. For any order with **no file
      uploaded**, email the customer for their Dropbox/art link (most trade
      shops send files after ordering).
- [ ] Check **ShopFlow**: advance jobs (`In Design → Design Complete`) and
      **deliver finished files** to customers who are ready.
- [ ] Check **new website chats/leads** (WrapGuru admin). Personally follow up
      any hot lead that didn't convert.

### 2. Midday — Content build (the main job, 60–90 min)
Build the day's content from **real completed shop work** using the AI content
tools. Aim for **1–2 published pieces/day**, each ending in a WrapGuru CTA
(quote / check my file / order).

Weekly rhythm (so there's no guessing):
| Day | Content | Tool | CTA |
|-----|---------|------|-----|
| Mon | Before/After reel of a finished wrap | ReelBuilder | "Get a quote" |
| Tue | Offer/static ad (feature $299 Production Pack or $199 File Output) | MetaAdFactory | "Order now" |
| Wed | Educational: "Is your file print-ready?" | ContentStudio | "Check my file" |
| Thu | Customer spotlight / testimonial | ContentStudio | "Start your wrap" |
| Fri | Promo / CTA post | MetaAdFactory | "Ask WrapGuru" |

Steps: pick 1–2 recent completed wraps → generate the piece → **publish via the
sanctioned publisher (content deploy)** → confirm it links back to WrapGuru.

### 3. End of day (15 min)
- [ ] Log anything that needs Trish's decision in a running list.
- [ ] Confirm nothing is stuck in ShopFlow / no order sat untouched.

      the free razor, printing is the paid blade — grows print sales without
      devaluing design; keep the "$199 value" visible).
- [ ] **Retargeting customer emails** — turn ON (pre-approved sequence) or leave
      OFF? Recommend: leave a single pre-approved follow-up on, or keep off.
- [ ] Confirm **Jackson has access** to: WrapGuru admin, ShopFlow, the content
      tools (ContentStudio / ReelBuilder / MetaAdFactory), ApprovePro.
- [ ] Give Jackson **one escalation path** for a real emergency (a number/email
      that reaches you or a backup).

## PART D — What is NOT allowed while you're away (safety)
- No new pricing or discounts beyond the approved standing promo.
- No sending a wrap to print without proof approval.
- No mass/blast emails beyond the approved retargeting sequence.
- No changes to WrapGuru, the store, or live systems — log it for Trish instead.
